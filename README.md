## Kullanılan Teknolojiler
 
- **HTML5** — `index.html`, sayfanın tüm içerik ve yapısını barındırıyor

- **Vanilla JavaScript** — `script.js`, etkileşimli davranışlar (menü, kaydırma efektleri vb.)
